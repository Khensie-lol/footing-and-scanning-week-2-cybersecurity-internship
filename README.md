## Project Overview

This repository presents my Week 2 practical work in cybersecurity. It documents two activities: domain footprinting using Kali Linux utilities and host discovery on my own local network using Zenmap.

The purpose of the practical was to understand how security practitioners gather and interpret information about a domain, identify devices responding on an authorised network, and present the observations in a structured report.

## Activities Covered

### 1. Domain Footprinting - W2-PM1

The report documents the use of six tools to review publicly visible information about `networkwalks.com`:

- **WHOIS:** Domain registration information.
- **WhatWeb:** Website technology identification.
- **nslookup:** DNS resolution.
- **curl -I:** HTTP response headers.
- **Wafw00f:** Web Application Firewall identification.
- **DNSRecon:** DNS record enumeration.

### 2. Local Network Discovery - W2-PM5

The report documents checking the local PC's network configuration, running a Zenmap Ping Scan, and reviewing the resulting network topology.

The latest scan recorded **four responding hosts**.

## Scope and Responsible Use

The domain footprinting activity was conducted within the written permission stated for the exercise. Network discovery was limited to my own local network.

The activities covered information gathering and host discovery only. No exploitation, authentication testing, bypassing of security controls or vulnerability validation was performed.

## Privacy Note

This is a public portfolio copy. Local device names, private IP addresses and MAC addresses have been withheld to avoid publishing information about a private network.

## Learning Reflection

This practical helped me understand that each reconnaissance tool reveals a different part of an environment.

The value comes from interpreting the results together, documenting what was observed, and avoiding unsupported conclusions. A detected technology version or responding host is a finding to review, not proof by itself that a system is vulnerable.
